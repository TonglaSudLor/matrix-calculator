# Matrix Lab

เว็บคำนวณเมทริกซ์เชิงสัญลักษณ์ คำตอบแสดงด้านบน พิมพ์สูตรและเมทริกซ์ในพื้นที่เดียวกัน

เว็บที่ deploy: <https://matrixcalculator-blue.vercel.app>

## รันบนเครื่อง

ต้องมี Python 3.9 ขึ้นไป, SymPy และ Node.js

```sh
python -m pip install -r requirements.txt
npm run dev
```

เปิด <http://localhost:3000> ตรวจแกนคำนวณด้วย `npm test`

## ใช้งาน

- พิมพ์ `i(3)` หรือ `I(3)` แล้วกด `)` เพื่อได้ identity matrix 3×3 ทันที กด Space หรือ Enter ภายในวงเล็บที่เติมให้อัตโนมัติก็ได้
- พิมพ์ `mat3` แล้วกด Space หรือ Enter: ได้เมทริกซ์ว่าง 3×3 หรือใช้ `mat2x3` สำหรับขนาด 2×3 ต้องกรอกครบก่อนคำนวณ
- ในช่องเมทริกซ์ กด Enter หรือ Tab เพื่อไปช่องขวา เมื่อสุดแถวจะขึ้นแถวใหม่
- หลังช่องสุดท้าย กด Enter เพื่อกลับไปพิมพ์สูตรต่อ กด `Ctrl+Enter` จากช่องเมทริกซ์เพื่อคำนวณ
- นอกช่องเมทริกซ์ กด Enter เพื่อแสดงคำตอบด้านบน
- ปุ่ม «คู่มือ» ด้านบนรวมวิธีใช้และรายการคำสั่งที่รองรับ หน้าเครื่องคิดเลขแสดงเฉพาะคำตอบและช่องพิมพ์สูตร
- พิมพ์ `(` แล้วระบบเติม `)` และวางเคอร์เซอร์ไว้ตรงกลาง พิมพ์ `)` เพื่อข้ามวงเล็บปิดที่มีอยู่ กด Backspace ใน `()` เพื่อลบทั้งคู่ ใช้ได้ในสูตรและช่องเมทริกซ์
- พิมพ์ `*` แล้วจะแสดงเป็น `×` อัตโนมัติในสูตรและช่องเมทริกซ์ ตัวแปร `x` ยังใช้ได้ตามปกติ
- ใช้ `+`, `-`, `*`, `^` รวมถึง `det(...)`, `transpose(...)`, `inverse(...)`, `trace(...)`, `rref(...)`, `simplify(...)`, `decimal(...)`, `toPi(...)`
- ตัวแปร เช่น `theta1`, `alpha`, `l2` จะยังอยู่ในผลลัพธ์ `theta1` แสดงเป็น `θ₁`
- ตั้งชื่อผลลัพธ์ได้ เช่น `A = i(3)` และใช้ `ans` อ้างผลล่าสุด
- ปุ่มตั้งค่ามุมขวาบนเลือก DEG (ค่าเริ่มต้น) หรือ RAD สำหรับ `sin`, `cos`, `tan` ที่รับมุมตัวเลข เช่น `2cos(30)` ใน DEG ได้ `√3`
- พิมพ์ตรีโกณมิติแบบย่อได้ เช่น `cosl1`, `sintheta`, `tan30` เทียบเท่า `cos(l1)`, `sin(theta)`, `tan(30)` ช่อง Expression จะแสดงวงเล็บเมื่อจบคำสั่งหรือกดคำนวณ
- เลขชี้กำลังจำนวนเต็มที่พิมพ์ด้วย `^` จะแสดงเป็นตัวยกใน Expression เช่น `2^2` เป็น `2²` และ `2^-2` เป็น `2⁻²`
- หลังคำนวณ กด «แสดงวิธีทำ» เพื่อดูขั้นตอนที่โปรแกรมบันทึกไว้ สูตรบางชนิดยังไม่มีขั้นตอนย่อย
- กด «กำหนดค่าตัวแปร» ได้แม้ยังไม่มีสูตร เพิ่มตัวแปรและค่าไว้ล่วงหน้าในป๊อปอัป แล้วกด «บันทึกค่า» ค่าจะใช้กับสูตรที่พิมพ์ภายหลังและจำไว้ในแท็บนี้ ช่องที่เว้นว่างยังคงเป็นตัวแปร กด «ล้างค่าทั้งหมด» เพื่อกลับไปดูผลเชิงสัญลักษณ์
- ปุ่ม «แทนค่า: เปิด/ปิด» ข้าง ANSWER สลับคำตอบระหว่างผลที่แทนค่าตัวแปรกับผลเชิงสัญลักษณ์ โดยไม่ลบค่าที่บันทึกไว้
- ข้างหัวข้อ ANSWER มีปุ่ม «เดิม», `simplify`, `decimal` ปุ่มจะใช้งานได้หลังคำนวณ และจัดรูปคำตอบโดยไม่แก้สูตรใน Expression
- ค่า `pi` ในโหมด DEG หมายถึง π องศา ถ้าต้องการคำนวณ `cos(pi) = -1` ให้เลือก RAD

รองรับเมทริกซ์ขนาดสูงสุด 4×4 ใช้เศษส่วนเป็นค่าเริ่มต้น
